# 奈叶主要招式与语音

本文整理高町奈叶在《魔法少女奈叶》系列动画、剧场版及游戏中使用过的主要攻击／拘束魔法，供语音 Mod 选材时参考。

## 主要招式

| 招式名称                                                | 语音                                                                                                                                                                                                | 招式说明                                                                                                                                                                                    |
|---------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Divine Shooter**                                      | 「シュート！」；加速时「アクセル！」                                                                                                                                                                | 初期代表性的诱导射击魔法。先形成 Divine Sphere，再发射可追踪、可由奈叶分别控制的魔力弹；施放快、能连射，用于牵制高速目标并弥补自身机动性不足。主要见于 TV 第 1 期。                         |
| **Accel Shooter**                                       | 「アクセルシューター！」；游戏短版「シュートッ！」／蓄力版「アクセル・シュートッ！」                                                                                                                | Divine Shooter 经卡匣系统强化后的多弹诱导射击。可同时控制十余至数十发魔力弹，兼具牵制、包围和拦截用途，是《A's》以后奈叶常用的中远程招式。                                                  |
| **Divine Buster**                                       | 「ディバイン……バスター！」；游戏短版「バスター！」                                                                                                                                                  | 奈叶最具代表性的直射砲击之一。以高密度魔力形成粗大光束，拥有高威力和较强的屏障贯穿能力；比 Starlight Breaker 更适合作为常规主砲。TV 第 1 期、剧场版及多部游戏均有使用。                     |
| **Divine Buster Full Power**                            | 「ディバインバスター、フルパワー！」                                                                                                                                                                | Divine Buster 的广域释放形态。在不显著降低威力的前提下扩大放射范围；TV 第 1 期第 9 话用于同时封印六枚 Jewel Seed。                                                                          |
| **Divine Buster Extension**                             | 「ディバインバスター・エクステンション！」                                                                                                                                                          | 《A's》中登场的超长距离强化型 Divine Buster。由 Raising Heart Excellion 辅助精密瞄准，兼具射程、弹速、精度、威力与屏障贯穿能力，适合作为远距离狙击语音。                                    |
| **Excellion Buster**                                    | 「エクセリオンバスター！」／「ブレイクシュート！」                                                                                                                                                  | Excellion／Exceed 模式下使用的大威力主砲，可在中距离进行有限的弹道控制。最大输出形态为 Force Burst，先用 Barrel Shot 固定目标，再作多重砲击；《A's》第 11、12 话为代表场面。                  |
| **Excellion Buster A.C.S.**（Accelerate Charge System） | 「アクセルチャージャー起動！ ストライクフレーム！」→「エクセリオンバスター A.C.S.、ドライブ！」→命中后「ブレイクシュート！」                                                                        | 高速突击砲。奈叶以 Strike Frame 形成半实体魔力刃，高速冲破对方屏障后在防御内部零距离释放 Excellion Buster。威力极高，但使用者也会承受近距离爆发的反冲与余波；代表场面为《A's》第 11 话。    |
| **Barrel Shot**                                         | —                                                                                                                                                                                                   | Excellion Buster 的前置复合魔法：同时执行砲管稳定、冲击波压制和不可视拘束，使目标固定并为后续主砲建立稳定弹道。动画中更像整套 Excellion Buster 流程的一部分，未确认奈叶单独喊出固定招式名。 |
| **Straight Buster**                                     | 「ストレイトバスター！」                                                                                                                                                                            | Excellion Buster 的直射应用型，强化命中后的反应炸裂效果；爆炸可在密集目标间连锁传播，以相对经济的魔力消耗实现较高的群体歼灭效率。主要见于《StrikerS》。                                     |
| **Restrict Lock**                                       | 动画代表句「捕まえた！」；游戏蓄力版同为「捕まえた！」                                                                                                                                              | 追踪型拘束魔法，以光环／光带锁住目标。奈叶经常先以此限制敌人，再接续 Divine Buster 或 Starlight Breaker；《StrikerS》第 25 话对 Vivio 的终结流程尤其典型。                                  |
| **Starlight Breaker**                                   | TV 第 1 期：「受けてみて、ディバインバスターのバリエーション！」「これが私の全力全開！」「スターライト……ブレイカー！」；剧场版：「うけてみて！ これが私の全力全開！」「スターライト……ブレイカー！」 | 奈叶的标志性终极集束砲击。把战场中散逸的残留魔力重新聚集后一次释放，因此战斗越激烈、周围残留魔力越多，潜在威力越大；缺点是集束时间长，通常需先拘束目标。                                    |
| **Starlight Breaker Plus / ex**                         | 主要仍为「スターライトブレイカー！」；常伴随「全力全開！」                                                                                                                                          | Starlight Breaker 的强化形态。`Plus` 延长蓄力以提高输出并附加结界破坏能力；`ex` 借助卡匣缩短准备时间并提高火力，是《A's》决战“三重 Breaker”之一。                                           |
| **Starlight Breaker ex Full Burst**                     | 「全力！ 全開！！！」「スターライト……ブレイカー！」「ブレイク……シュート！」                                                                                                                         | 《StrikerS》第 25 话使用的全方位形态。配合四基 Blaster Bit 从多个方向同时砲击，以精密控制摧毁 Vivio 体内的 Relic；威力和设备负担都极大。                                                    |
| **Hyperion Smasher**                                    | 「ハイペリオン・スマッシャー！」                                                                                                                                                                    | PSP 游戏《魔法少女リリカルなのはA's PORTABLE -THE GEARS OF DESTINY-》中的 Full Drive 专用大威力砲击。发动较慢，但正面光幕带防御判定，单发伤害属游戏最高级别之一。                           |
| **Maneuver A.C.S.**                                     | 通常以突击呼声为主，未确认统一的招式名喊声                                                                                                                                                          | PSP 游戏中的近距离突击／抓取动作，沿用 A.C.S. 的高速推进概念。它不是新的终极砲击，更适合选作铳枪突进、上挑或贴身爆发动作的语音参考。                                                        |
